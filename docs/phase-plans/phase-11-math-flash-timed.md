## 1. 目标

## 2. 题量口径（2026-11-08 修正，主人指正）

> **⚠️ 本节已被主人指正过一次。** 初版我按**现有代码的题池条件**（`a<=9 && b<=9`）算出"四关各 45 张"，那是错的 —— 那不是教材表。
> 正确口径是**人教版一年级上册口算表原样**（含 0），10 以内加法/减法是 **66 张**，不是 45 张。

### 2.1 四张教材表的确切结构

| 关卡 | 教材表 | 算式结构 | 题数 |
|---|---|---|---|
| L1 | 10 以内加法表 | `a,b ∈ [0,10]`，`a+b ≤ 10` | **66** |
| L2 | 10 以内减法表 | `0 ≤ b ≤ a ≤ 10` | **66** |
| L3 | 20 以内进位加法表 | `a,b ∈ [1,9]`，`10 ≤ a+b ≤ 18` | **45** |
| L4 | 20 以内退位减法表 | `a ∈ [10,18]`，`b ∈ [1,9]`，`得数 ∈ [1,9]` | **45** |

L3/L4 的结构与教材口诀表逐条对齐（已验证）：
- L3 按和分组：和=10 有 9 个、11 有 8 个 … 18 有 1 个（教材：9+1=10, 8+2=10 … 1+9=10, 9+2=11 …）
- L4 按得数组：得=1 有 1 个、2 有 2 个 … 9 有 9 个（教材：10-1=9, 11-2=9 … 18-9=9）

### 2.2 为什么不能直接套用固定 90s/150s

**66 张 ÷ 90 秒 = 每题 1.36 秒，扣掉 0.6 秒反馈动画后只剩 0.76 秒净思考。**
一年级孩子读题 + 心算 + 点选项至少 1.5 秒 → **L1/L2 在固定 90s 门下永远拿不到三星**。

| 关卡 | 题数 | 90s 内每题 | 扣 0.6s 反馈后净思考 | 150s 内净思考 |
|---|---|---|---|---|
| L1 / L2 | 66 | 1.36s | **0.76s ❌ 不可达** | 1.67s |
| L3 / L4 | 45 | 2.00s | 1.40s ✅ | 2.73s |

### 2.3 采用的方案（待你推翻）

**剔除含 0 的边角题 → 四关各 45 张 → 你的原始阈值 90s/150s 原样保留，一秒不改。**

| 关卡 | 教材表 | 剔除含0后 | 三星线 | 二星线 | 每题 |
|---|---|---|---|---|---|
| L1 10以内加法 | 66 | **45** | **90s** | **150s** | 2.0s / 3.33s |
| L2 10以内减法 | 66 | **45** | **90s** | **150s** | 2.0s / 3.33s |
| L3 20以内进位加法 | 45 | **45** | **90s** | **150s** | 2.0s / 3.33s |
| L4 20以内减法 | 45 | **45** | **90s** | **150s** | 2.0s / 3.33s |

为什么这样最干净：
1. **你的指令原样落地** —— 90 秒三星 / 150 秒二星，不需要任何"按关卡缩放"的花招，规则一句话说得清
2. 四关题量统一 45 → 每关时间预算完全一致 → **难度可比**（孩子在四关拿到同样的星 = "算得快"，不是"关卡短"）
3. 90 秒 ÷ 45 = 2.0 秒/题，扣 0.6 秒反馈后净思考 1.40 秒 —— 一年级孩子做 10 以内加减法的真实水平
4. 剔掉的 21~22 张是 `0+0`、`5-0`、`3-3=0` 这类**送分题**：一年级还没学到 0 的认识（第二单元），且对计时挑战零区分度 —— 瞬间答出只会稀释"速度"这个信号

### 2.4 备选：严格对齐教材表 66 张

如果你要求 L1/L2 严格出满 66 张（含 0），那么：

| 关卡 | 题数 | 三星线 | 二星线 | 后果 |
|---|---|---|---|---|
| L1 / L2 | 66 | **132s** | **220s** | 阈值必须按题量缩放（每题仍 2.0s / 3.33s） |
| L3 / L4 | 45 | **90s** | **150s** | 不变 |

- 一局约 **2.8 分钟**（45 张约 1.9 分钟），注意力压力明显更大
- L1/L2 的三星线变成 2 分 12 秒，与"1分半三星"的口号不再一致
- 好处：完全对齐教材表，送分题也练到

> ⚠️ **我选了"剔除含 0"，这是我的默认取舍，不是你的指令。** 两条路都成立，差别就两点：**① 是否出送分题 ② L1/L2 的阈值是 90s 还是 132s**。要改成严格 66 张，说一声即可。

## 5. 引擎改动（`current/engine/math-flash.js`）

### 5.1 题池重建

当前 `createQuestion()` 每次调用都**重新穷举全池 + 随机抽一张**，导致：
1. 同一题可能重复出现（如 `10+10` 可能出两次）
2. 无法保证"全部出完"

改为：启动时构建一次**去重的 45 张卡片池** → 洗牌 → 依次发牌。

```js
// 每关固定 45 张唯一知识点卡
function buildDeck(size) {
  const level = LEVELS[size];
  const seen = new Set();
  const cards = [];
  for (let a = 1; a <= 20; a++) {
    for (let b = 1; b <= 10; b++) {
      const answer = level.op === "+" ? a + b : a - b;
      if (!isValidCard(size, a, b, answer)) continue;
      const key = `${a}-${b}`;           // 去重键
      if (seen.has(key)) continue;
      seen.add(key);
      cards.push({ a, b, op: level.op, answer });
    }
  }
  return shuffle(cards);
}
```

各关合法性条件（在现有 `createQuestion` 基础上收紧，去掉 0 边角与重复）：

| 关卡 | 条件 | 说明 | 题数 |
|---|---|---|---|
| L1 | `a>=1 && b>=1 && a<=10 && b<=10 && a+b<=10` | 10 以内加法（教材表 66 张去掉 21 张含 0 的） | 45 |
| L2 | `a>=1 && b>=1 && b<a && a<=10` | 10 以内减法（教材表 66 张去掉 22 张 `a-0` / `a-a` 的） | 45 |
| L3 | `a<=9 && b<=9 && a+b>=10 && a+b<=18` | 20 以内进位加法（教材表原样，含和=10 那 9 张） | 45 |
| L4 | `a>=10 && a<=18 && b>=1 && b<=9 && a-b>=1 && a-b<=9` | 20 以内退位减法（教材表原样，含 `10-1` 那 9 张） | 45 |

> **L3/L4 与现有代码的差异**：现码 L3 是 `a<=10 && answer>=11`（多出 `10+1..10+9` 和 `10+10`，共 55 张），现码 L4 是 `a>=11`（漏掉 `10-1..10-9`，且 `a<=20` 多出 20 减几那 9 张）。新口径按教材表逐条对齐。
>
> **L1/L2 与现有代码的差异**：现码 L1 `a<=9 && b<=9`（漏掉 `10+x` 与 `x+10` 共 21 张），现码 L2 `a>=2`（漏掉 `1-b` 共 11 张）。新口径按教材表。
>
> **⚠️ 若改为严格 66 张口径**，L1 条件去掉 `a>=1 && b>=1`（允许 a 或 b 为 0）、L2 去掉 `b<a`（允许 `b=0` 和 `a=b`），阈值改按 §2.4 缩放。

### 5.1b `LEVELS` 的 minAnswer / maxAnswer 必须同步改

题池调整后答案范围边界变了，**不改会导致 `createOptions()` 造出越界干扰项**：

| size | 字段 | 现值 | 新值 | 原因 |
|---|---|---|---|---|
| 3 (L1) | minAnswer / maxAnswer | 2 / 10 | **2 / 10 不变** | 去掉含 0 的题后，答案区间仍是 2..10 |
| 4 (L2) | minAnswer | 0 | **1** | 去掉 `a-a=0`（`3-3=0`）后最小答案是 `2-1=1` |
| 4 (L2) | maxAnswer | 9 | **9 不变** | 最大仍是 `10-1=9` |
| 5 (L3) | minAnswer | 11 | **10** | 教材表含和=10 那 9 张（`9+1=10`、`8+2=10`…） |
| 5 (L3) | maxAnswer | 20 | **18** | 教材表最大是 `9+9=18`，去掉 `10+10=20` |
| 6 (L4) | minAnswer | 2 | **1** | 教材表含 `10-9=1` |
| 6 (L4) | maxAnswer | 19 | **9** | 20 以内退位减法得数最大 9（`10-1=9`） |

改完后每关答案区间（**已用脚本验证**）：
- L1 `2..10` / L2 `1..9` / L3 `10..18` / L4 `1..9`

`createOptions()` 用 `level.minAnswer/maxAnswer` 过滤干扰项。**已验证四关的每一个答案都能凑满 4 个不重复选项**（L2/L4 最窄：答案=1 → 干扰项 2,3,4；答案=9 → 干扰项 8,7,6），**选项生成逻辑本身不用改**。

### 5.1c 去重后与教材口算表的对应（复核结论）

四关各 45 张，逐条对齐人教版一年级上册口算表：

| 关卡 | 教材表 | 剔除后结构 | 小题数 |
|---|---|---|---|
| L1 | 10 以内加法表（66） | 去掉含 0 的 21 张 | 45 |
| L2 | 10 以内减法表（66） | 去掉 `a-0` 11 张 + `a-a` 11 张 | 45 |
| L3 | 20 以内进位加法表（45） | 原样，含和=10 那 9 张 | 45 |
| L4 | 20 以内退位减法表（45） | 原样，含 `10-1` 那 9 张 | 45 |

已验证 L3 按和分组为 9/8/7/6/5/4/3/2/1（和=10..18），L4 按得数组为 1/2/3/4/5/6/7/8/9（得=1..9）—— 与教材口诀表结构完全一致。

## 9. 移动端测试脚本改造（R5 展开）

当前脚本对每个 size 走：点难度 → 等 500ms → 测量 gameplay → 手动显示 complete panel → 测量。

算术闪卡的问题：**gameplay 阶段只等 500ms**，本来就没真打 10 题（脚本只测布局，不测玩法）。所以**脚本实际不会被打到 45 题**——它只做布局测量。

需要改的只有：
- 脚本 `GAME_SIZES['open-math-flash'] = [3,4,5,6]` —— **保持不变**（4 个有效关卡正好对上）
- 脚本手动填的 `complete-stats` 文案 `'用时 00:42 · 成功率 8 / 8（100%）'` —— 可保留（它是布局探针，不是真数据）
- **但**完成面板真实文案变成"答对 N / 45"后，若比探针文案长，需在脚本里同步成最长形态，确保布局断言覆盖真实文案

## 10. 开放问题（待你拍板，各带推荐默认值）

### Q1：含 0 的送分题要不要出？（**主人已指出教材表是 66 张，这条最关键**）
- **推荐默认：剔除**，四关统一 45 张，阈值 90s/150s 原样不动。
- 备选：严格 66 张（L1/L2 阈值自动缩放到 132s/220s，一局约 2.8 分钟）。
- 详见 §2.3 / §2.4。

### Q2：答错要不要扣时间？
- **推荐默认：不扣**。纯按总耗时评星，实现最简单，规则一句话说得清（"越快越三星"）。
- 备选：答错 +3 秒（防止乱点刷星）。代价：规则变复杂，孩子要理解"罚时"。

### Q3：最佳记录显示什么？
- **推荐默认：显示"最快用时"**（如"最快 01:08"），与新评星口径一致。
- 备选：显示"最高星数 + 那一局用时"。

### Q4：四关都 45 张，还是给入门关更少的题？
- **推荐默认：四关都 45 张**。四关同题量 → 同时间预算 → 星级可横向比较（"我在哪关最快"）。
- 备选：L1 给 30 张（对刚入学的孩子更友好），但会破坏跨关可比性。
