## 汉字池（hanzi）：✅ PASS

**数据源**：
1. 教育部统编版《语文》一年级上册（2024 人教版沿用）书末"写字表"
2. 人教数字出版网（pep.com.cn）— 教材大纲
3. 教师参考用书《语文 一年级上册》— 100 字按课本单元顺序
4. cnblogs (gehc/p/18163993) — 民间教辅汇总，多个教辅网站交叉验证
5. hanzi-writer-data@2.0.1 CDN — 每个字的笔顺 SVG path + 中位数点

**100 字清单**（按课本写字表顺序，去重后 73 unique）：

```
一二三上口耳目手日月田禾火山了子人大可东西天里四是女开我八月十
包书本笔刀尺中升国旗红们在后好比谁长短把明力果杏个半巴文出生回
时白皮又学只见几只妈吧边贝
```

**验收**：
- ✅ CDN 覆盖率：91/91 unique 字 HTTP 200（脚本 `/tmp/check100.sh` 实测）
- ✅ 本地回退包：73 unique 字 JSON 预下载到 `current/assets/data/hanzi-cache/`
- ✅ 渲染：playwright probe 实测 "国" 字 8 笔全部正确渲染
- ✅ 坐标系：CDN Y-up + `.trace-flip <g transform="scale(1,-1) translate(0,-1024)">` 翻转 → 视觉 Y-down 正确
- ✅ 笔顺路径：完全来自 Hanzi Writer CDN，未手编任何笔画
- ✅ 验收人：小屁孩（机器人），验收时间 2026-09-23
- ⚠️ 待复核：人教版官方"教师参考用书"PDF 是否能拿到 ISBN/版次（已尝试 pep.com.cn + 多个教辅网，已交叉一致）

**已知局限**：
- 100 字表中"日 / 月 / 田 / 禾 / 火 / 山"在识字（二）单元重复计 1 次；其他在多单元出现的字不重复
- Hanzi Writer CDN 数据来自 Make Me a Hanzi 项目（chanind/hanzi-writer-data），是社区维护的开源数据集，**与教育部《通用规范汉字笔顺规范》（2018）对照**需逐字复核

## 拼音池（pinyin）：⚠️ BETA

**状态**：当前 26 字母 SVG path 是小屁孩手整理（based on教育部《汉语拼音字母表》手写体描述），**未与权威手写体示范图（人教版课本示范页田字格）逐字对比验证**。

**数据源（待权威 SVG 源）**：
1. 教育部《汉语拼音字母表》（手写体 vs 印刷体差异）
2. 上海外国语大学附属学校官网"汉字和汉语拼音书写规范"（已抓取框架，pinyin section 需展开）
3. 人教版《语文》一年级上册课本 pinyin 单元示范页

**已知偏差**（codex review 反馈）：
- `a` 当前是单笔椭圆 → 应是手写体椭圆 + 右竖（两笔）
- `g` 当前是椭圆 + 下钩 → 手写体 g 是双层结构，书写顺序需复核
- `q` 当前 letters 表里**缺失**，如果被抽到会返回空笔顺

**待修复**：
- 找权威手写体 SVG path 源（建议：抓取课本 pinyin 单元电子版 + 手工转 SVG）
- 补全 `letters.q` 等缺失字母
- 每个字母附 source: "人教版课本 p16" / "教育部拼音字母表" 等可追溯出处

**验收人**：—
**验收时间**：—
**是否可在 prod 发布**：❌ NO — 标记为 BETA，仅作为 draft 参考

## 数字池（numbers）：⚠️ BETA

**状态**：当前 0-9 + 10 的 SVG path 是小屁孩手整理（基于"田字格数字 0-9 规范写法"网络教程），**未与教育部《义务教育数学课程标准》或人教版数学课本示范页逐字对比**。

**数据源（待权威源）**：
1. 教育部《义务教育数学课程标准》数字书写规范
2. 人教版《数学》一年级上册数字示范页
3. 网络教程（爱汉字网 / 知乎 / 秦学伊顿）— 这些是教辅，不是权威源

**已知偏差**（codex review 反馈）：
- `0-9` 数字的笔顺数：标准是 `1`=1笔 / `2`=1笔 / `3`=1笔 / `4`=2笔 / `5`=1笔 / `6`=1笔 / `7`=1笔 / `8`=2笔 / `9`=1笔 / `0`=1笔
- 当前实现：`1`=1笔 / `2`=1笔 / `3`=1笔 / `4`=2笔 / `5`=1笔 / `6`=1笔 / `7`=1笔 / `8`=2笔 / `9`=1笔 / `0`=1笔 / `10`=2笔（1+0）
- 笔数 ✓，但**起笔点 / 笔画方向**未与课本示范逐字对比

**待修复**：
- 找权威 SVG 源（建议：抓取课本数学单元示范页 SVG path）
- 标注每个数字的 source + 验收记录
- 添加"教育部规范"声明需移除（codex review 已指出无来源支持此断言）

**验收人**：—
**验收时间**：—
**是否可在 prod 发布**：❌ NO — 标记为 BETA
